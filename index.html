Coursework Project

Personal Webpage and Network Analysis

This project involves creating a personal webpage, deploying it with GitHub Pages, and investigating the network communication involved in accessing it.

The analysis will include DNS lookups, ping measurements, route tracing, and Wireshark packet inspection. Measurements and screenshots will be discussed in the coursework report.
